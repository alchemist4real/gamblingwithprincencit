# ♠ GAMBLING WITH PRINCE NCIT

Aplikasi Web Interaktif Flashcard Patologi Anatomi (PA) Blok 3.1 FK.
Menyajikan 40 sediaan histopatologi dan stasiun soal teori vignette klinis lengkap sesuai silabus Robbins.

🌐 **Live Production**: [https://gamblingwithprincencit.vercel.app](https://gamblingwithprincencit.vercel.app)

## 🎮 Fitur Utama
- **Desain Monokromatik 2-Warna**: Biru #314fba & Putih #ffffff solid murni (Zero black drop shadows, kartu 100% solid).
- **Suite 5 Gaya Animasi Shuffle**:
  1. 🃏 *Kocok Riffle Kasino & Kaskade Air Terjun*
  2. 🌪️ *Kocok Pusaran Meja Kasino (Table Wash)*
  3. ✨ *Akrobatik Card Spring Flourish*
  4. ⚡ *Kocok Potong Tumpuk (Triple Packet Cut)*
  5. 🌀 *Kocok Badai Siklon 3D (Helix Tornado)*
- **Rapid Card Riffle Engine**: Tahan panah layar / tombol keyboard / stick PS untuk streaming kartu berkecepatan tinggi (60–120 FPS) dengan kemiringan aerodinamis dan audio tik real-time.
- **Dukungan Penuh Stick PS (PlayStation Controller)**: Kendali via DualShock 4 / DualSense PS5 dengan umpan balik getaran Dual-Rumble dan lencana tombol otomatis.
- **Gestur Sentuh Intuitif**: Drag panggung 3D real-time, usap ke atas untuk reveal, tarik ke bawah untuk menutup modal, mode Android & tablet adaptif.
- **Strict Zero-Spoiler**: Gambar sediaan mikroskopis polos tanpa label identifikasi sebelum dibuka.
